# 日本全国絶景マップ

日本地図から絶景スポットを探せる、個人用のお出かけ計画アプリです。ビルド不要の静的サイトです。

## 使い方
- `index.html` をブラウザで開くだけで動きます(インストール不要)。
- 季節タブで見頃の絶景に絞り込み、地図の県をタップで一覧、検索・フィルター・ランキング・「どこ行く?」で行き先を探せます。
- スポットの「行きたい / 行った」とメモは、**この端末のブラウザ**に保存されます。

## スマホでも使う(公開手順)
どちらか一つで、無料で公開できます。公開URLをPC・スマホの両方で開いてください。
- **Netlify Drop(いちばん簡単)**: https://app.netlify.com/drop に、このフォルダ(`zekkei-map`)をドラッグ&ドロップします。発行されたURLを開き、スマホではブラウザのメニューから「ホーム画面に追加」します。
- **GitHub Pages**: GitHubにリポジトリを作成して push し、Settings → Pages → Branch を `main` / `/ (root)` に設定します。
- 「現在地から近い順」と、ホーム画面への追加(PWA)は **HTTPS** の公開URLで有効になります(`file://` では使えません)。
- アプリを更新して再公開すると、次回のオンライン表示で新しい内容に切り替わります。

## データのバックアップ・端末間の移行
管理画面(`#/admin`)の「JSON書き出し」でファイルを保存し、別の端末の「JSON読み込み」で復元します(読み込みは現在の記録を置き換えます)。

## スポットの追加
管理画面から手で追加するか、候補JSONを「情報源からの候補を取り込む」に貼り付けます。候補は `tests/sample-candidates.json` の形式です。重複判定のうえ、確認してから取り込めます。
取り込むのは名称・所在地・指定の有無・出典リンクなどの事実情報だけにしてください(口コミ本文や動画の内容は転載せず、リンクで持ちます)。
写真・Google Map・出典リンクのURLは `http://` または `https://` のものだけが有効です。それ以外の形式は保存・取り込み時に無効として除かれます。

## 開発者向け
- テスト: `node tests/run.js`
- 地図データの再生成: `node tools/build-map.js`
- 座標の照合: `node tools/verify-coords.js`
- 写真の収集: `node tools/fetch-photos.js`(Wikimedia Commons。ライセンス表示が必要な写真は詳細ページに撮影者を表示します。`photos.generated.js` に出力し、`--write` を付けない限り `photos.js` は上書きしません)
- 初期データは `data/spots.js`。組み込みデータを更新しても、個人の記録は消えません。

## 既知の制限
- アイコンはSVGのみです。一部の環境(特にiOS)では、ホーム画面のアイコンが既定の表示になることがあります。
- 端末間の自動同期はありません(手動のJSON移行のみ)。
- 写真はオンライン時のみ表示され、オフラインでは季節色の背景になります。
